FEELZ RUN · JOURNAL PICTURES

Each find in the game is a picture you flip over to read. Make one image per entry below and save it as
FEELZ_RUN_web\assets\journal\<ID>.webp (or .png renamed to .webp), 4:3, about 1000 x 750.
Until a picture exists, the game shows a faded sepia view of that mission's place instead.

STYLE LINE (paste before every prompt):
Graphic-novel game concept art, bold black ink outlines, cel shading, muted dusty colours with gold accents, close-up still life, the object fills the frame, soft light from one side, worn and lived-in, 4:3 landscape. No readable text, no logos, no people's faces.
