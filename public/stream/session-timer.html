Session timer

Add your sections and how long each one runs. Every press of your Stream Dock button starts the next section, and a buzzer sounds when its time is up.

  1. In OBS, add a Browser source to each scene you stream from, paste the link, and set it to 1920 x 1080 (1080 x 1920 in the Vertical dock).
  2. Tick "Shutdown source when not visible" and "Control audio via OBS".
  3. On your Stream Dock "Session timer" key, choose the OBS "Source visibility" action for that source.
  4. Press once to start a section, press again to hide it. The next press starts the next section.
  5. To start the run from the first section again, press the key twice within 3 seconds.
